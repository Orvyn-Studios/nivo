# Nivo by Orvyn

Aplicación de escritorio para Windows, independiente de StarOptimizer.

El código fuente y el desarrollo están en la rama [feature/nivo-mvp](https://github.com/SnoW-099/nivo/tree/feature/nivo-mvp).

Versión en desarrollo. La compilación y aceptación nativas siguen pendientes; todavía no hay una beta de Windows validada ni una release publicada.
